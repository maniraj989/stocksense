# StockSense Reporting Documentation

This directory contains report templates, schemas, and operational instructions for StockSense reporting services.

## Available Reports
- **Sales Invoice PDF**: Itemized transaction receipt generated on demand.
- **Purchase Order PDF**: Vendor procurement document with order details.
- **Inventory Valuation PDF & Excel**: Landscape catalog valuation by cost and retail value.
- **Data Exports**: Comprehensive CSV and Excel workbooks for Products, Suppliers, Sales, Purchases, Stock Movements, and Alerts.
